Edge Computing Website – Project Plan

1. Project Description

I will create a multi-page educational website about Edge Computing. The website will explain what edge computing is, how it works, its advantages and disadvantages, and how it is used in everyday life and different industries.

The website will use HTML, CSS and JavaScript. It will also include an interactive quiz and an HTML Canvas drawing.

2. Minimum Outcomes

- Create at least four connected website pages.
- Use HTML to organize headings, paragraphs, images, tables and links.
- Use CSS to style the website and create a consistent layout.
- Include navigation links between all pages.
- Provide informative content about Edge Computing.
- Include comments in the source code.
- Organize the files into separate folders.

3. Advanced Outcomes

- Use JavaScript to create an interactive quiz.
- Use buttons to check answers and reset the quiz.
- Display the quiz score using JavaScript.
- Use HTML Canvas to draw an edge computing diagram.
- Make the website responsive so it works on different screen sizes.

4. Website Layout

| Page | Description |
|---|---|
| Home | Introduction and overview of Edge Computing |
| How It Works | Explanation of how edge computing operates |
| Applications | Examples of edge computing in real-world industries |
| Quiz | Interactive quiz and Canvas diagram |
| Sources | References and image credits |

5. Timeline

| Stage | Tasks |
|---|---|
| Step 1 | Research Edge Computing and plan the website layout |
| Step 2 | Create the HTML pages and navigation |
| Step 3 | Apply CSS styling and organize the website |
| Step 4 | Add JavaScript quiz functionality |
| Step 5 | Create the Canvas diagram and test the website |
| Step 6 | Review the content, check links and prepare the presentation |

6. Project Goal

My goal is to create an organized, informative and functional website that demonstrates my understanding of HTML, CSS, JavaScript and HTML Canvas.
